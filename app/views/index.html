Centralised file system (Supplier journey)

This prototype explores the idea of a centralised file hub that can be used by suppliers to manage their assurance artefacts.

Live dashboard (supplier journey)

One of the identified pain points for suppliers was a lack of clarity or communication from the trust. We discussed the potential benefits of a live dashboard and some of the features that might appeal to suppliers, chiefly a task tracking and notification system.

Exploring the centralised file system (or file hub)

A centralised file system has been floated as a potential solution to some of the assurance woes faced by both trusts and suppliers, as having assurance documents in one place makes it easier for everyone to track. It might also encourage re-using existing assurance data rather than making suppliers perform duplicative work.

These pages were prototyped for collaboration sessions and discussion.

  • filehub summary
  • filehub upload A labelling system might help make files easier to find and help users understand the contents without opening it. (Essentially encouraging users to add metadata to files)
  • filehub upload summary What happens if you assign a file to a particular trust but there is already one assigned with the same label? A labelling system would allow these sorts of interactions and enable a primitive sort of versioning.

MVP (trust journey)

User research told us that there is a definite appetite for some sort of centralised file system and live service, but we needed to develop a simpler prototype for a service that could realistically be delivered in a short time frame.

This prototype was user needs tested, but not by domain experts.

Manage health technology assurance (supplier journey)

In this prototype the supplier can manage their assurance portfolio through a live dashboard connected to a centralised file storage system. The user can respond to assurance requests from their customer (an NHS organisation), manage existing assurance information for a product and manage assurance information at an organisational level.

Assure a medical device or product (trust)

In this prototype the trust can request assurance information for their chosen medical device or product (in this case a fictional app called 'Moustache Health Monitor App'). Through a live dashboard connected to a centralised file system, the user can request standard assurance forms that might be expected for a particular device or ask bespoke questions tailored to their orgnanisational needs.

To encourage knowledge sharing between trusts, many of the pages present the option to share information with other trusts. Trusts are also encouraged to use existing assurance information for their chosen product (if available) to reduce the admin burden on the supplier or manufacurer's side.
