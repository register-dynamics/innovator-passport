Start page

Feedback

Users found the single search field confusing and expected to see a list of devices on the next page instead of a list of suppliers.

Changes made

The page has two input text fields, allowing the user to search by supplier name, device name or both. The intro paragraph is intended to clarify that this journey is still about finding a supplier, even if they find the supplier by device.
